# ② README‑zh.md（中文手册）
```markdown
# read‑sci — 科研论文三阶段阅读翻译工具
`read‑sci` 面向科研人员的 Agent Skill：分三阶段阅读、翻译、批判性解析学术论文，维护可复用Excel术语库，实现多篇论文之间术语翻译保持统一。

## 功能简介
1. 📄 支持输入格式：PDF、Word(DOCX)、PPTX、HTML、JATS‑XML、LaTeX、Markdown、RTF、纯文本、扫描件（OCR识别能力取决于运行平台）
2. 🚩 三阶段受控工作流
   - **阶段1：背景与已有研究**：摘要、引言、相关工作翻译；提炼研究问题、研究缺口、论文贡献；输出领域前置知识；提取术语写入术语库。
   - **阶段2：方法、实验、结果**：段落级原文‑中文双语对照翻译；解析数据集、纳入排除条件、基线、评价指标、消融实验、统计结果；保留原始语言的实验配置块。
   - **阶段3：讨论、结论与局限性**：翻译讨论与结论；评估每条主要结论的证据支持强度；区分作者自述局限与从研究设计推断出的局限；明确说明**论文没有证明什么**，给出可行后续研究方向。
3. 📒 自动术语库：在 `read‑sci.md` 同目录自动生成 `academic‑glossary.xlsx`；**人工首选译名优先级最高，工具不会自动覆盖人工修改内容**。

## 快速开始
### 基础调用（默认模式，自动在技能同目录生成术语库）
read‑sci paper.pdf
plaintext
执行后自动进入**阶段1**。
阶段完成后输入继续指令推进下一阶段：
> 可用继续指令：`继续`、`下一部分`、`继续进行`、`next`、`go on`

### 自定义术语库路径（平台相对路径解析异常时使用）
当术语库被生成到错误文件夹，手动指定术语库完整路径：
read‑sci paper.pdf glossary_path="D:\my‑terms\my‑glossary.xlsx"
plaintext

## 术语库 `academic‑glossary.xlsx` 字段说明
| 字段 | 说明 |
|---|---|
| Original term | 英文原术语 |
| Domain | 所属研究领域 |
| 人工首选译名 | **用户手动编辑，优先级最高；Skill永远不会自动覆盖此字段** |
| 机器建议译名 | Skill生成的候选参考译名 |
| 生效译名 | 实际输出译名：优先取人工首选译名，为空时回退机器建议译名 |
| Occurrence count | 术语累计出现次数 |
| Source paper | 首次提取该术语的论文来源 |
| Last updated date | 最后更新时间 |
| Status | `Pending`待确认 / `Confirmed`已确认 |

> 新提取词条默认标记为`Pending`，人工审阅后手动修改为`Confirmed`。

## 输出证据标记说明
输出中三类标记区分信息来源：
- `[原文陈述]`：论文作者原文表述
- `[基于原文的推断]`：基于论文内容推导得出
- `[外部补充知识]`：来自论文以外的外部知识；可核验会标注来源，无法核验标记`一般性解释（未外部核验）`

> `译注：`代表翻译歧义补充注释。

## 常见问题
1. **没有生成 `academic‑glossary.xlsx`？**
   - 运行账号对技能所在文件夹缺少写入权限；会输出待更新词条，但不会写出Excel文件。
2. **术语库生成到其他文件夹？**
   - 当前Agent平台不支持“相对于skill文件解析相对路径”；使用参数 `glossary_path=` 指定绝对路径。
3. **报错无法加载契约文件**
   - 缺失完整`references`文件夹，请完整克隆/下载整个仓库，不要单独复制 `read‑sci.md`。

## 注意事项
- 扫描文档效果完全依赖平台OCR识别质量；识别失败工具会主动提示，请提供可编辑版本文档。
- 工具忠实还原论文原文，不会自动修正论文本身错误；论文观点不等于本工具观点。
- 本工具仅用于科研辅助，不构成医疗、法律、金融专业建议。
